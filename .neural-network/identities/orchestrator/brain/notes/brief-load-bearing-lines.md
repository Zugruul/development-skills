When briefing a dev agent for a restyle/refactor with frozen logic, name the load-bearing specifics: exact code locations (function + approximate lines), the test files with their pinned contracts (STATIC_IDS, id/class assertions), and the finalized design artifact path with its decision status ("Option C, as-is, final"). The agent then spends its exploration budget on genuine unknowns (payload fields, API shapes) instead of re-deriving settled decisions. Links: [[live-tweaks-as-brief-amendments]].
