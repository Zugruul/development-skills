When a human drips small scope refinements onto an in-flight UI task (a size, a font, a gap), relay each to the RUNNING dev agent as a brief amendment carrying its own red-first test pin — never file separate tasks or restart the lane. The branch stays one reviewable unit, history stays a red/green audit trail per tweak, and the reviewer can verify each pinned value independently. Links: [[prescription-ack-closes-round-cap]].
