## §7.1 — local-state manifest gains `.claude/project.local.yaml` (ignore)

**Section changed**: §7.1 (canonical local-state manifest). §7.1's list is
declared "Initial policies" and has grown additively before; this delta records
the newest addition because the path is not just runtime state but a **config
overlay**, which deserves an explicit contract note.

**Addition**: `ignore	.claude/project.local.yaml` — the OPTIONAL machine-local
overlay for `.claude/project.yaml`, introduced by the remote-compute
skill (#524, `docs/design/remote-compute-plan.md`).

**Contract**:
- `config.py load_config()` merges the overlay over the committed config for an
  explicit allowlist of keys only (`LOCAL_OVERLAY_KEYS`, today exactly
  `compute`); every other key in the local file is deliberately ignored, so a
  gitignored file can never silently override committed configuration.
- A missing overlay file is the normal case, never an error.
- Rationale: which remote machines a clone can reach is a property of the
  MACHINE (mirrors `~/.claude/compute/resources.yaml`), not of the repository —
  committing availability entries would advertise one person's hardware to
  every clone and leak local topology into shared history.
