## §13.2 — CHANGED (temporary STT default engine flip, issues #491/#424)

**Section changed**: §13.2 (STT engine selection; original decision recorded in
docs/spec-deltas/applied/ast-051.md, issue #333: whisper is the default).

**What changed**: `web-speech` is the DEFAULT STT engine until the whisper
sidecar contract gap (#424) closes. ast-051 made whisper the default on the
assumption of a working local sidecar; in practice the shipped client POSTs
`/transcribe` (multipart field `audio`) while the bare `whisper-server` the
capability launches serves only `/inference` (field `file`), so a fresh
profile defaulting to whisper gets a voice path that can NEVER transcribe —
observed live 2026-07-28 as "talks, nothing captured, no reply" (issues
#490/#491's human reports).

**Contract now**:
- `sttEngineChoice()` returns `"whisper"` only when `uiState.sttEngine` is
  explicitly `"whisper"`; anything else (unset, unknown) resolves to
  `"web-speech"`.
- An explicit, persisted whisper choice still wins — the flip changes only
  the unset-default branch.
- The settings-panel hint names Web Speech as the default and points at
  #424 as the condition for whisper's return.

**Reversion condition**: when #424 lands (the sidecar serves the documented
`/transcribe` contract end to end), flip the default back to whisper per
ast-051's original privacy-first decision and update the hint + pins in
plugins/spec-workflow/tests/section-assistant-stt.sh accordingly.

**Also under this task (additive, no §13.2 text change needed)**:
- Web Speech runs with `interimResults = true`; interim segments stream
  through the engine contract's new optional third `onInterim` callback into
  a live pending bubble in the chat overlay (`#ast-stt-pending`), removed
  when the turn resolves (final transcript, failure, or no-speech cancel).
  Endpointing (#454) is unchanged: only FINAL segments arm/reset the
  silence timer.
- The mic control's dot is capture truth (#490): lit iff a live STT turn or
  the visualizer's own mic capture is active, synced every drawViz frame.
